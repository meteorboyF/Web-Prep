CSE 4165 Web Programming

Two screenshots. Ninety minutes. Plain HTML and CSS.

This site does two things: it teaches every HTML and CSS concept with a live editor you can break, and it walks through the twelve past-paper prototypes one build step at a time — structure first, code second.

Learn

Five parts, from the document skeleton to print stylesheets. Every concept that can be demonstrated has a runnable example instead of a paragraph describing it.

Solve soon

Twelve prototypes from six past papers, each broken into ordered build steps with a cumulative preview, the annotated colour palette, and a note on what to skip when the clock runs down.

Drill soon

A ninety-minute timer, a blank two-pane editor, a random prototype, and a printable checklist of what to type first.

Where this is up to

Being built in phases. Phase 1 is the deployment skeleton — its whole job is to prove that the relative paths work on GitHub Pages before any content is written on top of them.

Deployment self-check

The bug this site is most likely to hit is a path that starts with a slash. It resolves correctly on a server root and fails under /Web-Prep/, so it works locally and breaks live. Rather than trust a grep, this panel reports what actually loaded on whatever host you are reading it from.

What resolved on this page

  • Stylesheets ./assets/css/
  • Scripts ./assets/js/
  • Data files ./data/
  • Images ./assets/img/
  • Local storage checking

Also worth checking Open Part 1. It sits one folder deeper and reaches its CSS with ../. If both pages pass, the two path cases that matter are covered.
