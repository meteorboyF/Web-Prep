How this works

No build step and no framework. It runs from a web server or by opening index.html from the filesystem, and it keeps working offline after the first visit — the only external file is the code editor, which falls back to a plain textarea if it cannot load.

Every path is relative, because GitHub Pages serves this from a /Web-Prep/ subfolder and a single leading slash would work locally and 404 live. The panel below reports what actually resolved on whatever host you are reading this from.
