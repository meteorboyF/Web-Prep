CSE 4165 · 90 minutes · 2 × 15 marks

Exam checklist

One page. Press Ctrl+P and put it beside the keyboard.

1. Before you type anything

  1. Read both prototypes. Decide which is easier and start with that one.
  2. Find every red arrow. Count the hex codes — they are marks.
  3. Name the regions out loud: header, hero, card row, sidebar, form, footer.
  4. Decide grid or flex for the outer shape only. The inside can wait.

2. The reset, from memory

* { margin: 0; padding: 0;
    box-sizing: border-box; }

body { font-family: system-ui,
       Arial, sans-serif; }

img { max-width: 100%; display: block; }

a { text-decoration: none;
    color: inherit; }

input, select, textarea, button {
  font: inherit; color: inherit; }

3. The order of attack

  1. Skeleton and reset.
  2. All the HTML, with * { outline: 1px solid red } on.
  3. Palette into :root, straight off the paper.
  4. Outer container: grid or flex, widths, gaps.
  5. Section by section, top to bottom.
  6. Details: radius, borders, shadows.
  7. Compare against the image.

4. Time budget

0–5Read both papers, pick the order.
5–45First prototype, all seven steps.
45–85Second prototype.
85–90Compare both. Fix nothing new.
  • At 45 minutes, move on whatever state the first one is in.
  • Two three-quarter answers beat one perfect one.

5. Patterns you will need

  • margin-right: auto — logo left, links right.
  • display: grid; grid-template-columns: 240px 1fr — sidebar shell.
  • flex: 1 1 260px — card row that wraps itself.
  • justify-content: space-between — label left, value right.
  • margin-top: auto — pin something to the bottom of a flex column.
  • position: relative parent + absolute child — badges, overlays.
  • aspect-ratio: 1; border-radius: 50% — circular avatar.
  • border-left: 4px solid — coloured stripe on a card.
  • border-radius: 999px — pill or chip.
  • overflow: hidden — make children respect a radius.

6. One component, one variable

<article class="card" style="--c: #1975d1">

.card { background: var(--c); }
  • Four coloured cards is one rule block, not four.
  • Same for chips, tags and progress bars.
  • Six of the twelve past papers need this.

7. Do not waste time on

  • Icons. A Unicode character or a coloured square.
  • Images. <img src="a.jpg" alt="">, or a div with aspect-ratio.
  • Web fonts. A network request that may not resolve.
  • Hover states. A screenshot has none.
  • Responsive. One max-width: 768px query at the end, if there is time.
  • Exact gradients on an unannotated paper.

8. When it looks wrong

  • Wider than you set → box-sizing.
  • Mystery gap → margin collapse, or default margins.
  • Flex row overflows → min-width: 0 on the item.
  • Badge in the page corner → parent is missing position: relative.
  • Square corners through a radius → overflow: hidden.
  • Rule does nothing → missing semicolon on the line above.
  • Gradient invisible → it is in background-color.
  • Text greyed on a coloured card → opacity instead of an alpha background.
  • Sidebar panels stretched → align-content: start.
  • Everything broken → * { outline: 1px solid red }.

9. Last five minutes

  • Every annotated hex actually used?
  • Both prototypes on screen, even if rough?
  • Any element wider than its container?
  • Outline debug rule removed or commented?
  • Files saved with the names you were asked for?
